# 🔎 Project Highlights

### 🪲 The Cicadas Are Coming

Investigates whether **13-year or 17-year periodical cicadas** receive greater public attention.

**Key techniques:**

* Time-series analysis
* Hypothesis formation
* Historical event overlays
* Independent dataset validation
* Comparative visualization

**Key result:** Historical word-frequency patterns aligned more closely with the **17-year cycle**, and independent print-mention data supported the observation.

---

### ☕ A Plant-Based Coffee Shop

Analyzes survey responses from approximately **1,170 coffee drinkers** to determine which dairy alternatives and sweeteners should be stocked.

**Key result:** Oat milk was the leading plant-based dairy alternative, while granulated sugar was the dominant sweetener preference.

---

### ✈️ Flight Delays

Analyzes **5,000 domestic flight records** to investigate how delays vary throughout the week and whether passenger volume is associated with delays.

**Key result:** Sunday had the highest delay percentage (~23.4%), while Tuesday had the lowest (~15.4%). Higher passenger volume was also associated with higher delay rates.

---

### 🦁 Lion Attacks

Uses regression analysis to investigate the relationship between **moonlight and lion attacks**.

The project combines:

* Linear regression
* R² evaluation
* Prediction
* Independent supporting evidence
* Correlation vs. causation reasoning

The analysis found a strong negative relationship between evening moonlight and reported lion attacks.

---

### 🎨 Art as Data

Transforms Piet Mondrian paintings into structured geometric data.

The project explores:

* Painting complexity
* Dimensions over time
* Color usage
* Artistic evolution
* Anomaly detection

A disputed 1926 painting was compared against authenticated paintings from the same period.

---

### 🚲 E-Bike Stopping Distances

Compares **linear and quadratic regression models** for predicting stopping distance.

The quadratic model improved the fit from:

`R² = 0.968 → R² = 0.989`

The analysis also demonstrates why statistical fit should be combined with **physical reasoning and model validation**.

---

### 🐘 Tusked Elephants

Investigates whether historical ivory poaching may have influenced elephant tusk size.

The project uses regression to control for elephant body size rather than relying only on raw averages.

**Key finding:** After accounting for shoulder height, the relationship between body size and tusk length was substantially weaker in the post-poaching cohort.

---

### 🌍 Our World Connected

Explores the growth of global internet adoption from **1990 onward**.

The project combines internet-user data with historical population data to calculate the percentage of the world's population connected to the internet.

**Key results:**

* Global internet adoption passed **50% in 2019**
* Internet users exceeded **5.3 billion by 2022**
* North America was the first continent to pass 50% adoption
* Africa remained below 50% in the latest dataset analyzed

# 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/lotfiab1/Data-Analyst-Projects.git
cd Data-Analyst-Projects
```

### 2. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### 3. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the project folder you want to explore and run the notebook cells sequentially.
